## S24.3.1 — Load the surface strictly

**State:** Closed (2026-11-17)

**Acceptance:**

- `CliSurface.load` raises `AppException` for a key that names no field, at the
  top level or in a `commands` entry, and the message lists each such key by
  its dotted path (`comands`, `commands.0.hlep`).
- Every surface the existing tests load still loads.

Settled contract: `CliSurface` and `CommandSurface` use `StrictDataclassMixin`;
the message is `Invalid CliSurface: unknown key(s) <dotted paths>`. A document
with no `cli` table but a top-level `name` is read as the surface, so its other
top-level keys fail too.
