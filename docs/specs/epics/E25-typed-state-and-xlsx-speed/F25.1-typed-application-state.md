`rn-forge-fastapi` declares an application's state once, with its attributes and
types, and a route receives it through `Depends`, so a misspelt or missing
resource fails type checking instead of at request time.

## Context

A FastAPI application that keeps long-lived resources on `app.state` reads them
back as `request.app.state.<name>`, which is untyped: Apollo does so 195 times.

Apollo is the motivation, not a gate: every acceptance line here is checked
inside pykit ([ADR-0008](../../../adr/ADR-0008.md)).

## S25.1.1 — Settle the typed-state API

**State:** New

**Acceptance:**

- The story records one settled contract covering: how an application declares
  its state attributes and their types; how a route receives them through
  `Depends`; how a misspelt or mistyped attribute fails under
  `task typecheck`, and how a test proves it without failing the repo's own
  type check; what happens at startup when a declared resource is absent; and
  how the state interacts with the application's `lifespan`.
- The contract names the public symbols and the package module that exports
  them, and states whether any existing public API changes.
- Options considered and rejected are listed with one line each.

## S25.1.2 — Build typed application state

**State:** New · **Depends on:** S25.1.1

**Acceptance:**

- A test application declares its state with the settled API and a route reads
  an attribute through `Depends`; the request succeeds and the value is the
  one set at startup.
- Reading a misspelt attribute, or one as the wrong type, is a pyright error;
  the check that proves it runs under `task typecheck` or `task test`, as
  S25.1.1 settled.
- An application with a declared resource absent fails at startup in the way
  S25.1.1 settled; a test asserts the exception and its message.
- The state's setup and teardown run with the application's `lifespan`, as
  S25.1.1 settled; a test asserts the order.
- The package's guide describes the API, and the package's `CHANGELOG.md` has an
  entry under `[Unreleased]`.
- The new symbols are re-exported from the package facade, and `task validate`
  passes.
