## Current behaviour

All in `packages/rn-forge-tooling/src/rn_forge/tooling/install/lifecycle.py`:

- `_install` (`:226-280`) builds an `undo` list of callables:
  displaced-directory rename (`:246`), `rmtree(version_dir)` (`:248`), one per
  link from `_place_link` (`:252`), `_restore_file(state_path)` (`:254`),
  `_restore_current` (`:266`).
- The `except BaseException` block (`:268-278`) runs
  `for step in reversed(undo): step()`. An exception from one step escapes the
  loop, so remaining steps never run, and the new exception replaces `exc`:
  the caller sees the undo error, not the `AppException` wrapping the
  initiating failure.
- The `finally` (`:279-280`) always runs
  `shutil.rmtree(work, ignore_errors=True)`. On a forced reinstall the old
  version sits at `work/displaced` (`:238,245`); if
  `displaced.rename(version_dir)` fails during undo, the finally deletes the
  only copy.
- Contract text: `packages/rn-forge-tooling/docs/guides/lifecycle.md:79-83`
  ("the steps already taken are undone in reverse, and the previous version is
  active again") and the `install` docstring "everything it did has been
  undone".

## Tests first

Both carry
`@pytest.mark.xfail(strict=True, reason="S22.6.3: <what is missing>")`, so the
suite stays green and a later fix flips them to a strict failure that prompts
removing the marker.

1. `test_a_failed_undo_step_does_not_stop_remaining_recovery`: install 1.0.0,
   set `source.newest = "2.0.0"`, then
   `upgrade(product(source, fail_migration=True), home=home)`. Wrap
   `lifecycle_module.atomic_symlink` (monkeypatch) to call the real one on
   call 1 (placing the link) and raise `OSError("undo failed")` on call 2 (the
   link restore). Expect
   `pytest.raises(AppException, match="migration exploded")`. Assert
   `not home.version_dir("2.0.0").exists()`. Today the `OSError` escapes,
   `rmtree` never runs, so it fails on the raises and on the assert.
1. `test_a_failed_restoration_keeps_the_displaced_version`: install 1.0.0, then
   `install(product(source, fail_build=True), home=home, force=True)`, with
   `pathlib.Path.rename` monkeypatched to raise `OSError("restore failed")`
   when `self.name == "displaced"`. Expect
   `pytest.raises((AppException, OSError))`. Assert some file under
   `home.product_dir.rglob("bin/tool")` reads `"tool 1.0.0\n"`. Today
   `finally` deletes `.work`, so none exists.
