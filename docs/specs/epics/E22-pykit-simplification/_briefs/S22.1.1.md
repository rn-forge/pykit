- Settled by the reviewer, 2026-11-16: classification applies to each `## `
  section of a page (the title, metadata table and text before the first `## `
  form a "preamble"; a `<!-- BEGIN derived ... -->` block is "derived" and is
  counted but never classified or cut). A section takes the one class that
  describes most of it; do not split a section. The classes:
    - **future design**: how not-yet-built work will be built or what is undecided
      (feature `## Design`, `## Open questions`, design of a `New` or deferred
      item). Example: E7's design of Azure adapters.
    - **durable decision**: a choice between alternatives, with its reasons, that
      no ADR already records (`## Considered and rejected`, a settled option
      comparison). Example: E19's distribution decision text that exists only in
      the feature page.
    - **current usage**: how the shipped code behaves or how to use or develop it,
      which `architecture/` or `guides/` or a package `docs/` owns or should
      own. Example: a closed feature's configuration table or command
      walk-through.
    - **acceptance**: stories, their `**Acceptance:**` lines, the feature
      `## Acceptance` block, `Predecessors`, `Entry criteria`, and the metadata
      table. Example: a story's acceptance bullets.
    - **historical evidence**: what was tried, measured, reviewed or changed,
      dates, commands run, outcomes, review findings. Example: a cutover run
      log, a Sonar remediation round, "what the review changed". The commit
      message is the owner of such material
      ([docs/\_structure.md](../../../_structure.md)'s routing list), but a
      closed feature file stays ([specs/\_structure.md](../../../_structure.md)
      keeps closed feature files), so this class is cut only to a one-line
      outcome.
