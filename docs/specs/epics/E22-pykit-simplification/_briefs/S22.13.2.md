## Measurement

Throwaway script outside the repository (scratchpad): generate a synthetic
workspace in a temp directory with N members, each with 5 dependencies, one
optional list and one group, for N = 10, 100 and 500, plus a `releases/` tree of
the same sizes with one shipped page. Count `Path.read_text` calls per path
across `check_requirements(root)` and `pending_umbrella(...)`, using
`PYKIT_MEASURE_OUT`-style JSON Lines if convenient (see
`docs/guides/performance-baselines.md` for the harness fields: inputs, wall
time, counts). Record N, reads per file and total reads in Result. Rule: change
code only if some file is read more than a constant number of times that grows
with N.
