# S22.3.1 — Keep contract tests independent of source layout

Brief for
[S22.3.1](../F22.3-tests-and-measurements.md#s2231-keep-contract-tests-independent-of-source-layout),
at `1a8da87`.

## Goal

Make commons tests assert public behavior, not private calls or story IDs, with
no loss of collected cases. Only `packages/rn-forge-commons` changes.

## Settled

- Tests exercise contracts, not source layout; sleeps and AST checks are not
  deleted wholesale (E22 `design.md`, "Refactor tests before moving
  implementation").
- Cross-package and generated-file rules stand (ADR-0002; kiln-owned files).
- Delete the orphan test and leave `TaskPool.shutdown`'s `future is None` branch
  (`tasks.py:~372-374`) in place; no public path reaches it, and removing the
  branch is a code change for F22.4 (reviewer, 2026-11-14).
- The cli fixture (`test_options.py:26-34`), auth clock patch
  (`oidc/test_verifier.py:149-156`) and fastapi heartbeat
  (`test_sse.py:135-156`) are carried by S22.5.1, S22.8.3 and S22.10.2; this
  story touches commons only (reviewer, 2026-11-14).

## Current behaviour

- `packages/rn-forge-commons/tests/fs/test_blocks.py` has nine tests named
  `test_s18_7_1_<n>_...`: `_1_`..`_5_` at lines 29-48 (`TestMarkers`) and
  `_6_`..`_9_` at lines 101-125 (`TestEndIndent`; `_9_` is parametrized).
- `tests/runtime/test_tasks.py:84-103` (`TestTask`) calls `Task._start()`
  directly on the pytest main thread. `_start` (`runtime/tasks.py:161-172`)
  sets `threading.current_thread().name`, so the runner is renamed.
- `tests/runtime/test_tasks.py:310-312`
  (`TestTaskPoolAdvancedShutdown.test_shutdown_ignores_task_without_future`)
  writes `pool._tasks["orphan"]`; `submit` (`tasks.py:279-281`) always sets a
  future, so no public path reaches it.
- `tests/runtime/test_tasks.py:~420-437`
  (`TestTaskPoolMapSettled. test_cancelled_item_becomes_failed`) polls
  `pool.executor._work_queue` with `time.sleep(0.001)`.

## Change

- **Change:**
    - `tests/fs/test_blocks.py`: rename the nine tests by behavior, dropping the
      `s18_7_1_<n>_` prefix (e.g. `test_end_indent_defaults_to_indent`,
      `test_end_indent_applies_to_the_end_marker_only`, `test_html_end_indent`,
      `test_render_writes_begin_indented_and_end_at_margin`,
      `test_end_indent_is_not_validated`, `test_extract_reads_either_end_form`,
      `test_render_replaces_either_end_form`, `test_remove_and_round_trip`,
      `test_default_output_is_unchanged`). Bodies and parameters unchanged.
    - `tests/runtime/test_tasks.py` `TestTask`: replace the four `_start` tests
      with `TaskPool(max_workers=1)` + `submit` +
      `task.future.result(timeout=1)` / `pool.shutdown`: thread name equals the
      task name inside `run`; a failing task sets `task.error` to the
      `ValueError` and `future.result()` re-raises it with the same message;
      `run` was called. Add one assertion that `threading.current_thread().name`
      is unchanged in the test thread.
    - Delete `test_shutdown_ignores_task_without_future`; shutdown with submitted
      tasks stays covered by `TestTaskPoolShutdown`.
    - `test_cancelled_item_becomes_failed` (private `pool.executor._work_queue`
      poll plus sleep): keep its behavior assertions; if the queued state can be
      observed publicly (e.g. `pool.tasks`), poll that with a bounded deadline,
      otherwise leave it and say why in `## Result`.
- **Leave alone:** all source under `src/`; `tests/test_facade.py`; auth
  `test_facade.py` / `test_conformance.py` (real architecture checks); every
  other package; generated files.
