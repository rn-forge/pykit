# S22.7.3 — Organize shared HTTP cases

Brief for [S22.7.3](../F22.7-web.md#s2273-organize-shared-http-cases), at
`bef7973`.

## Open questions

None. Everything below is settled by the reviewer; the owner has nothing to
decide before implementation.

## Goal

`packages/rn-forge-web/src/rn_forge/web/conformance/cases.py` is one 1,890-line
table of 117 cases across 18 areas. Split it by HTTP subject into focused
private modules behind the same facade, with every case ID, expectation and
adapter driver unchanged.

## Settled

- Settled by the reviewer, 2026-11-15: `rn_forge.web.conformance` and
  `rn_forge.web.conformance.cases` keep every public name (`CASES`,
  `case_by_id`, `cases_for`, `cases_provided_by`, plus the `types` names).
  This is a split inside one package behind its own facade, not an alias
  across packages, so ADR-0002 does not apply. No case, ID, `depends_on`,
  `requires` or expectation changes.
- Settled by the reviewer, 2026-11-15: new private modules in
  `packages/rn-forge-web/src/rn_forge/web/conformance/`, each exporting one
  tuple of `ConformanceCase` (line ranges are in `cases.py` at `bef7973`):
    - `_problem.py` `PROBLEM_CASES`: areas `problem` (`:153-202`, `:624-652`) and
      `auth` (`:663-730`).
    - `_writes.py` `WRITE_CASES`: `concurrency` (`:203-283`), `idempotency`
      (`:489-543`), `patch` (`:1467-1598`), `soft-delete` (`:1714-1853`),
      `timestamps` (`:1406-1418`).
    - `_pagination.py` `PAGINATION_CASES`: `pagination` (`:284-488`) and
      `read-mask` (`:1599-1713`), with the token constants (`:111-137`).
    - `_transfer.py` `TRANSFER_CASES`: `transfer` (`:914-1405`) and `operations`
      (`:1419-1466`).
    - `_platform.py` `PLATFORM_CASES`: `health` (`:544-623`, `:653-662`),
      `casing`, `tracing`, `deprecation`, `discovery`, `security`, `cors`
      (`:731-913`).
    - `_shared.py`: only what two or more groups use (`_JSON`, `_PROBLEM`,
      `_problem_body`, `_TRACEPARENT`, ...). A constant used by one group moves
      into that group's module.
- Settled by the reviewer, 2026-11-15: `cases.py` keeps `CASES` as the
  concatenation of the five tuples plus the three lookup functions, and its
  `__all__`. Each area appears in exactly one group module.
- Settled by the reviewer, 2026-11-15: order. `cases_for(area)` order is
  unchanged. The global `CASES` order changes only where regrouping
  un-interleaves `problem`/`health` (`:544-662`); drivers resolve `depends_on`
  through `case_by_id`, not position. A dependency must still be resolvable by
  ID.
- Settled by the reviewer, 2026-11-15: the policy under test is already
  consumed, not re-derived (see Current behaviour). No adapter change belongs
  in this story, and no one-line consumption fix is needed. Do not add
  `next_link_header` to adapters; neither adapter emits `Link` (S22.9.3 and
  S22.10.2 own any decision there).
- Settled by the reviewer, 2026-11-15: no shared transfer codec change. Record
  the measurement plan in `## Result` and leave `transfer.py` alone; the
  likely outcome is "no duplication worth a codec" (see below).
- Docs: `packages/rn-forge-web/docs/reference/conformance.md:7` documents
  `rn_forge.web.conformance.cases`, which still exists; private `_*.py`
  modules are not added to the reference. Docs build in strict mode, so run
  `task docs:build` only if `task validate` does not cover it.

  single literal; helpers `cases_for` (`:1855`), `case_by_id` (`:1860`),
  `cases_provided_by` (`:1872`). Shapes and `redact` are in `types.py`
  (`ConformanceCase` `:80`, `RequestSpec` `:62`, `redact` `:110`). Facade:
  `conformance/__init__.py:1-33`, re-exported in `web/__init__.py:28-41`.

  `tests/test_conformance.py` (120 passed), sqlalchemy

  the facade (`rn_forge.web.conformance`); nothing imports `conformance.cases`

  in every adapter path (`django/exceptions.py:113`,
  `django/drf/transfer.py:556`, `fastapi/problem.py:106`,

- Transfer buffering: the codec is in `web/transfer.py` (negotiation `:82`,
  `content_disposition` `:141`, problem builders `:185-255`); no row buffering

- Import guards: web has none today (`grep` for `sys.modules`, `find_spec` in

  what those pull in.

## Change

- **Change:** create the five group modules and `_shared.py` by moving, not
  rewriting, the case literals; rebuild `CASES` in `cases.py`. Capture the ID
  fixture first (Tests first, item 1). Keep each module under ~450 lines where
  possible; `_transfer.py` is the largest (~540) and may split `operations`
  back out if that reads better.
- **Leave alone:** every case body, `types.py`, `conformance/__init__.py`'s
  public names, `transfer.py`, `idempotency.py`, `pagination.py`,
  `problem.py`, all adapter packages, `web/__init__.py`.
