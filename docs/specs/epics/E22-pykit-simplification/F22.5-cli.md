Keep the small CLI layer, and make repeated invocation predictable.

## Context

`options.py:125-142` sets the process console mode for JSON/quiet but does not
reset it for a plain invocation. Same-process command tests and embedded CLIs
can inherit the previous mode. `app.py:162-168` also calls idempotent logger
initialization, which can ignore later invocation log-level/file options. An
autouse fixture manually resets globals and hides that lifecycle. The package
has only four source modules and 574 lines; a new command framework would add
complexity.

## S22.5.1 — Specify and restore console lifetime

**State:** New

Add consecutive same-process invocation cases. Set the effective mode for every
root invocation and restore prior process state at the appropriate invocation
boundary, including exceptions. Keep subcommand inheritance.

**Acceptance:**

- JSON → plain, quiet → plain, failed → plain and nested root/subcommand
  invocations produce the expected output and exit codes.
- Conflicting quiet/JSON options fail without leaking state into the next
  invocation; INFO → DEBUG and two successive log-file paths honor each
  invocation.
- CommonOptions remains a value contract; console mode is still owned by
  commons.

## S22.5.2 — Keep one option and error path

**State:** New · **Depends on:** S22.3.2

Review CliApp and declarative surfaces for repeated option application and
exception translation. Consolidate only where two paths promise identical
behavior.

**Acceptance:**

- Generated and hand-registered commands exercise the same
  inherited-option/error matrix.
- Help output, standard options, declared surface and exception exit codes
  remain covered; scalar/list surface tables report key-specific configuration
  errors.
- Cold invocation measurements justify any import deferral; no blanket file
  split.

## Acceptance

- S22.5.1: JSON → plain, quiet → plain, failed → plain and nested
  root/subcommand invocations produce the expected output and exit codes.
- S22.5.2: Generated and hand-registered commands exercise the same
  inherited-option/error matrix.
