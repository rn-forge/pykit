Fix cache/claim edge cases and remove duplicate neutral policy while keeping
native Django extension points.

## Context

`drf/idempotency.py:54-58` returns the execute sentinel when a record expires
after a failed claim, without owning the slot. `drf/pagination.py:43` accepts
strings such as `--1` and `²` before `int` raises. `models/cache.py` joins
composite keys with dots, so different tuples collide. Auth routes and transfer
mixins also combine several responsibilities.

## S22.9.1 — Claim before execution

**State:** New

Retry the atomic cache claim when an observed entry disappears. Keep in-flight,
mismatched-body and completed replay outcomes distinct.

**Acceptance:**

- A controlled failed-add/expired-get interleaving allows execution only after a
  successful claim; competing callers never both execute under that
  interleaving.
- Existing replay, scope isolation, TTL, mismatch and in-flight cases still
  pass.
- The solution does not claim to solve execution beyond claim expiry without a
  separately chosen lease contract.

## S22.9.2 — Use unambiguous values

**State:** New

Parse page sizes with a deliberate invalid-input policy, and use structural
composite cache keys while preserving supported scalar normalization.

**Acceptance:**

- Both pagination classes handle malformed signs, Unicode digits, huge values,
  zero, negatives and normal values without an unhandled conversion exception.
- Load/set/get distinguish `(a.b, c)` from `(a, b.c)` and preserve documented
  scalar lookups.

## S22.9.3 — Thin auth and transfer composition

**State:** New

Consume auth policy/codecs from F22.8. Separate transfer import/export/batch
concerns only where native mixin composition stays clear. Reuse web wire policy;
keep ORM transactions, serializer validation and Django sessions local.

**Acceptance:**

- Adapter integration cases retain cookie/CSRF, session rotation, auth-denial
  and readiness behavior.
- Import/batch dry runs, row-index errors, authorization, rollback and exports
  retain framework-level coverage.
- Large queryset/export measurements show query count and peak memory; a
  refactor must not accidentally add one query per row.

## Acceptance

- S22.9.1: A controlled failed-add/expired-get interleaving allows execution
  only after a successful claim; competing callers never both execute under
  that interleaving.
- S22.9.2: Both pagination classes handle malformed signs, Unicode digits, huge
  values, zero, negatives and normal values without an unhandled conversion
  exception.
- S22.9.3: Adapter integration cases retain cookie/CSRF, session rotation,
