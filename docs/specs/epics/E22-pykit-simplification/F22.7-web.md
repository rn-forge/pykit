Keep wire policy in web, make readiness deadlines truthful, and organize
conformance by subject.

## Context

`health.py:230-239` waits on futures inside a ThreadPoolExecutor context:
leaving the context waits for unfinished work, so a timeout cannot bound
reporting latency. Sequential relative waits also give checks different
effective deadlines. `conformance/cases.py` holds 1,890 lines across multiple
HTTP concerns.

## S22.7.1 — Decide synchronous check lifetime

**State:** New

Reproduce timeout behavior with event-blocked checks. Settle deadline origin,
concurrency bounds, ownership and shutdown for checks that Python cannot
forcibly stop. Avoid solving latency by spawning unlimited abandoned workers.

**Acceptance:**

- A decision records common-deadline semantics and a bounded worker/reuse
  policy, with explicit behavior for stuck checks and shutdown.
- No claim is made that timing out a synchronous callable cancels its execution.

## S22.7.2 — Implement bounded reporting

**State:** New · **Depends on:** S22.7.1

Apply the decision without waiting for an unfinished worker on the response
path. Exercise direct web calls and Django readiness.

**Acceptance:**

- A readiness call reports required/optional failures before a blocked check is
  released; tests release workers in cleanup.
- Several slow checks share the documented deadline rather than receiving serial
  timeout budgets.
- Repeated timeouts do not grow workers/queued checks without bound; async and
  sync aggregation retain their intended contract.

## S22.7.3 — Organize shared HTTP cases

**State:** New

Split conformance definitions by HTTP subject behind their existing public
surface. Keep request/response hashing, pagination and problem rendering policy
framework-free; adapters should consume it instead of re-deriving it.

**Acceptance:**

- All existing case IDs and their behavioral expectations remain addressable and
  framework adapter conformance still runs.
- No framework dependency enters web, and test-support extraction does not add
  runtime imports.
- Transfer buffering measurements identify actual duplication before proposing a
  shared codec change.
