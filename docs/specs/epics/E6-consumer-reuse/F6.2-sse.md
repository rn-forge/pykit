Three applications hand-rolled server-sent-event framing, each slightly
differently: IntelliBuild's run stream, Apollo's job stream and PhotoTidy's
event broker. `sse-starlette` already does the framing, heartbeat and disconnect
handling correctly. This feature added a thin `rn-forge-fastapi` wrapper for the
things it does not do.

**Outcome:** `rn_forge.fastapi.sse.sse_response` shipped on 2026-11-01 behind
the `sse` extra. Usage is in the `rn-forge-fastapi` wiring guide
(`docs/guides/wiring.md`) and the API page `docs/reference/sse.md`.
[F17.6](../E17-local-first-web-app-extraction/F17.6-durable-job-queue.md)'s
job-event stream is built on it.

## Context

Apollo's rebuild is the concrete consumer: `sse_response` replaces its
hand-written frame function, comment heartbeat and `StreamingResponse` loop. It
keeps its own code until this ships and its pins move.

## Design

The module is gated behind an extra because importing `sse-starlette` patches
`uvicorn.Server.handle_exit`, a process-wide side effect
([ADR-0003](../../../adr/ADR-0003.md)). It has no conformance case, because both
framework drivers run every case with no skips and `rn-forge-django` has no SSE
adapter. Trace Context ([F4.2](../E4-standards-rebaseline/index.md)) removed the
correlation-header parameter of the 2026-09-19 design.

## S6.2.4 — Stream from a scaffolded application

**State:** Closed (2026-11-01)

**Acceptance:** the FastAPI application that
[F9.8](../E9-release-readiness/F9.8-scaffolded-acceptance.md) scaffolds,
installed with `rn-forge-fastapi[sse]` from built wheels, serves an
`sse_response` endpoint; a client reads its data frames, a heartbeat, and a
terminal problem frame when the generator raises.

## Acceptance

```bash
set -euo pipefail
absent() { local rc=0; rg -q --hidden --glob '!.git' "$@" </dev/null || rc=$?; [ "$rc" -eq 1 ]; }
cd packages/rn-forge-fastapi
grep -q '^sse = \["sse-starlette' pyproject.toml                   # S6.2.2
uv run pytest -q tests/test_sse.py                                 # S6.2.2
absent '\bsse\b' src/rn_forge/fastapi/__init__.py                  # S6.2.2
absent 'text/event-stream|ServerSentEvent' ../rn-forge-web/src/rn_forge/web/conformance  # S6.2.2
uv run pyright && uv run lint-imports                              # S6.2.2
test -f docs/reference/sse.md                                      # S6.2.3
uv run --group docs mkdocs build --strict                          # S6.2.3
```

S6.2.4 runs as part of F9.8's scaffold tests.
