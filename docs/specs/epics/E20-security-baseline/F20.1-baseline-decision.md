Settle which controls make up the pykit security baseline, and which of them
fail the build as opposed to only reporting. The decision is recorded as an
[ADR](../../../adr/index.md). Every other E20 feature depends on it, and settles
its open questions here.

## Stories

### S20.1.1 — Decide the baseline and record it as an ADR

**State:** Closed

**Acceptance:**

- The ADR names each required control (dependency audit, licence inventory,
  source scan, secret scan, push protection, SBOM, attestation, `SECURITY.md`,
  Scorecard), and says for each whether it fails the build or only reports.
- The ADR settles the tool choices left open on F20.2 to F20.5.
- The ADR states what the baseline claims and does not claim, and that auth
  security tests stay in [E13](../E13-auth/index.md).
- The open questions on F20.2 to F20.5 are resolved and removed.

The decision is [ADR-0015](../../../adr/ADR-0015.md).
