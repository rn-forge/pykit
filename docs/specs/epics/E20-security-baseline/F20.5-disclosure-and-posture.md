Say how to report a vulnerability and show the baseline's state. The repository
gets a `SECURITY.md`, OpenSSF Scorecard runs in CI, and each release gets an
evidence page listing the baseline results.

## Design

Decided in [ADR-0015](../../../adr/ADR-0015.md): the evidence page sits beside
its release, at `docs/releases/release-<n>/`. The reporting channel is GitHub
private vulnerability reporting. Scorecard reports and sets no threshold.

## Stories

### S20.5.1 — `SECURITY.md`

**State:** Closed

**Acceptance:** `SECURITY.md` at the repository root gives the reporting channel
and the supported versions.

### S20.5.2 — OpenSSF Scorecard

**State:** Active

**Acceptance:** a Scorecard run is part of CI and its result is recorded.

### S20.5.3 — Per-release evidence page

**State:** Closed

**Acceptance:** each release has a page listing the result of every baseline
control, and the release runbook says to fill it at the cut.

## Acceptance

- S20.5.1: `SECURITY.md` exists with both sections.
- S20.5.2: the Scorecard workflow runs.
- S20.5.3: the docs build passes with the evidence page.
