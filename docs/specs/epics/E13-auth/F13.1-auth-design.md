# F13.1 — Auth design

|  |  |
| -- | -- |
| **State** | Active |
| **Parent** | [E13](index.md) |
| **Iteration** | [Release 7](../../../releases/release-7/index.md) |

| **Predecessors** | [ADR-0006](../../../adr/ADR-0006.md) |

Discuss, settle and record [the E13 design](design.md): an industry-standard
auth pattern that any new rn-forge web application can adopt. This feature holds
the work; the design itself lives on its own page so every later E13 feature can
build on it.

## Stories

### S13.1.1 — Settle the design

**State:** Closed (2026-10-26)

**Acceptance:** The owner has answered every open question or deferred it with a
trigger, the design has no open questions left, and the design and
[the patterns page](patterns.md) agree with the answers.

### S13.1.2 — Record the decisions

**State:** New

**Acceptance:**

- Each [proposed decision](design.md#proposed-decisions) the owner accepts is an
  ADR listed in the [decision log](../../../adr/index.md), and a rejected one
  is listed under
  [Considered and rejected](design.md#considered-and-rejected).
- Every implementation feature the design implies exists in [E13](index.md) with
  stories and acceptance, and no code change precedes its feature.

### S13.1.3 — Evaluate the libraries

**State:** New

**Acceptance:**

- Each candidate in [the library evaluation](design.md#library-evaluation) is
  assessed against its criteria, with its maintenance status, and the result
  is recorded in [Libraries](design.md#libraries): the library pykit binds, or
  the requirement no candidate met for each component pykit writes.
- [Package responsibilities](design.md#package-responsibilities) and
  [What this replaces](design.md#what-this-replaces) agree with the result.

## Acceptance

- Every open question is answered or deferred with a trigger, and
  [the design](design.md) and [the patterns page](patterns.md) agree (S13.1.1).
- Every accepted proposed decision is an ADR, every rejected one is recorded
  under [Considered and rejected](design.md#considered-and-rejected), and
  every implementation feature the design implies exists in E13 with stories
  and acceptance (S13.1.2).
- Every library candidate is assessed and the result recorded in the design
  (S13.1.3).
