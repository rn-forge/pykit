`rn-forge-fastapi` binds the same HTTP surface and security defaults as an
`APIRouter`, as [Package responsibilities](design.md#package-responsibilities)
lists for it.

## Context

It covers:

- The [HTTP surface](design.md#http-surface) as an `APIRouter`.
- Server-side sessions over a `SessionStore`, using the session library S13.1.3
  chose, with the rules in
  [Sessions and cookies](design.md#sessions-and-cookies); refusal of unsafe
  stores outside debug mode.
- The synchronizer-token CSRF check, pre-session tokens, the `csrf-failed`
  problem and the origin check ([CSRF](design.md#csrf)).
- `current_principal` and `requires` dependencies; bearer callers resolved to an
  account; one credential per request.
- Rate limiting, audit events and the revocation race tests, matching F13.5's
  behavior case for case.

Its stories are written by S13.1.4 ([F13.1](F13.1-auth-design.md)) once the
library evaluation names what pykit binds; S13.1.4 then sets `Iteration` to
Release 7. Until then no code change starts here.
