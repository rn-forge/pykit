# F13.7 — Remove the legacy auth flows

|  |  |
| -- | -- |
| **State** | Active |
| **Parent** | [E13](index.md) |
| **Iteration** | [Release 7](../../../releases/release-7/index.md) |
| **Predecessors** | [F13.5](F13.5-django-binding.md), [F13.6](F13.6-fastapi-binding.md) |
| **Source** | Owner decision, 2026-10-26 |

Remove the locally issued JWT flows and the auth code the new surface replaces,
as [What this replaces](design.md#what-this-replaces) lists, with no aliases
([ADR-0002](../../../adr/ADR-0002.md)).

## Context

[ADR-0006](../../../adr/ADR-0006.md) removes the locally issued JWT flows. The
other rows of [What this replaces](design.md#what-this-replaces) are done by
earlier features: F13.2 moves or deletes the commons and web code, F13.3 drops
the role clauses, and F13.5 and F13.6 resolve bearer callers to accounts. This
feature removes what is left and checks the whole table, except ngkit's row,
which ngkit's epic owns.

## Stories

### S13.7.1 — Remove the JWT flows

**State:** Closed

**Acceptance:**

- `rn_forge.django.auth.jwt` and `rn-forge-django`'s `jwt` extra are gone.
- No extra, dependency group or `uv.lock` entry names
  `djangorestframework-simplejwt`.
- The `auth.saml` views, `SampleSAMLLoginAPIView` and the `auth.basic` views,
  which issue tokens through `LoginExchangeViewMixin`, are gone with it, with
  their tests.

### S13.7.2 — Remove the replaced Django auth code

**State:** New

**Acceptance:**

- `BaseCredentials`, `LoginPayload`, `AuthorizationViewMixin`,
  `PermissionKeyViewMixin` and `AuthorizationPermission` are gone, with their
  tests.
- `BaseLoginViewMixin`, `BaseLoginAPIView` and `LogoutAPIView` are gone, with
  their tests; `auth_urlpatterns` serves login and logout (owner decision,
  2026-10-28).
- `AuthorizedAPIView` and `AuthorizedModelViewSet` keep their names and check
  `PermissionKeyPermission`, so the `User`, `Group` and `Permission` viewsets
  still require their `permission_key` (owner decision, 2026-10-28).
- `rn-forge-django`'s `saml` extra is gone, and no extra, dependency group or
  `uv.lock` entry names python3-saml or xmlsec. The Django auth guide points a
  SAML IdP at a broker.

### S13.7.3 — Close the replacement table

**State:** New

**Acceptance:**

- A check in this feature's acceptance finds every removed symbol of
  [What this replaces](design.md#what-this-replaces) absent from `packages/`.
- `rn-forge-web` holds only the wire contract, and `rn-forge-commons` has no
  `auth` extra.
- The Django and FastAPI guides, the root `README.md` and the changelogs
  describe the new surface only, and record each removal as breaking.
- Both strict MkDocs builds pass.

## Acceptance

- The locally issued JWT flows, the login views built on them and simplejwt
  are gone (S13.7.1).
- The replaced Django credentials, base login views and mixins are gone, and
  so are the `saml` extra and python3-saml (S13.7.2).
- Every non-ngkit row of the replacement table is done, and the docs describe
  only the new surface (S13.7.3).

```bash
set -euo pipefail
absent() { local rc=0; rg -q --hidden --glob '!.git' --glob '!CHANGELOG.md' "$@" </dev/null || rc=$?; [ "$rc" -eq 1 ]; }
for s in JWTAuthentication JWTCredentials JWTUtils LoginExchangeViewMixin \
  JWTAuthenticationViewMixin UserTokenView BaseCredentials LoginPayload \
  SampleSAMLLoginAPIView AuthorizationViewMixin PermissionKeyViewMixin \
  AuthorizationPermission BaseLoginViewMixin BaseLoginAPIView LogoutAPIView \
  JwksCache any_role all_roles; do
  absent -w "$s" packages
done
absent -i simplejwt packages uv.lock
absent -i -e 'python3-saml' -e 'xmlsec' packages uv.lock
absent -F 'rn-forge-commons[auth]' packages
uv run pytest
uv run pyright
sh docs/_update_board.sh --check
```
