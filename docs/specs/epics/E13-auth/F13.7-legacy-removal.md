# F13.7 — Remove the legacy auth flows

|  |  |
| -- | -- |
| **State** | New |
| **Parent** | [E13](index.md) |
| **Predecessors** | [F13.5](F13.5-django-binding.md), [F13.6](F13.6-fastapi-binding.md) |
| **Source** | Owner decision, 2026-10-26 |

Remove the locally issued JWT flows and the auth code the new surface replaces,
as [What this replaces](design.md#what-this-replaces) lists, with no aliases
([ADR-0002](../../../adr/ADR-0002.md)).

## Context

It covers:

- `rn_forge.django.auth.jwt` and Django's `jwt` extra; simplejwt leaves every
  extra and group.
- `BaseCredentials`, `LoginPayload`, the `auth.saml` views and
  `SampleSAMLLoginAPIView` (the sample moves to the guide), the `auth.basic`
  views, `AuthorizationViewMixin`, `PermissionKeyViewMixin` and
  `AuthorizationPermission`.
- Django's `saml` extra depends on `rn-forge-auth[saml]`.
- The Django and FastAPI guides and changelogs describe the new surface only.

Its stories are written by S13.1.4 ([F13.1](F13.1-auth-design.md)) once the
library evaluation names what pykit binds; S13.1.4 then sets `Iteration` to
Release 7. Until then no code change starts here.
