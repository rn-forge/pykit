# F10.6 — Apply the refactor audit

**Status:** done · **Implemented:** 2026-09-25 · **Owner:** pykit · **Epic:** [E10](index.md)

**Depends on:** [F10.5](F10.5-validation.md).

**Source:** `plans/reviews/docs-refactor-audit.md`.

An audit of the refactor found content lost from pages rewritten in place, a spec model that diverged from kiln's, and release text that could not be followed. This feature applies its findings. The audit's "Implementation log" records each finding's outcome and every judgement call.

## Stories

### S10.6.1 — Apply the findings

**Status:** done (2026-09-25)

**Acceptance:**

- Every finding in the audit has an outcome in its implementation log.
- The owner's answers to AQ1–AQ4 are recorded where they apply.
- The root site and all seven package sites build with `mkdocs build --strict`.

```bash
set -euo pipefail
absent() { local rc=0; rg -q --hidden --glob '!.git' "$@" || rc=$?; [ "$rc" -eq 1 ]; }
uv run --group docs mkdocs build --strict
for d in packages/*/; do (cd "$d" && uv run --group docs mkdocs build --strict); done
absent '\*\*Readiness' docs/specs docs/releases
```
