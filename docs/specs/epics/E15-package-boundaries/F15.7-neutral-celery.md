# F15.7 — Framework-neutral Celery app factory

|  |  |
| -- | -- |
| **State** | New |
| **Parent** | [E15](index.md) |
| **Tags** | deferred |
| **Predecessors** | — |
| **Source** | [E15 design](design.md#celery), idea `django-optional-areas` (retired into E15) |
| **Entry criteria** | a non-Django application needs Celery |

Make `rn_forge.django.celery`'s app factory usable without Django, likely in
commons behind a `celery` extra, with the caller passing its own config object
and task packages.

## Context

`RETRYABLE_TASK_KWARGS` is already neutral. `make_app` is Django-specific only
in its default `config_source="django.conf:settings"` and its argument-less
`autodiscover_tasks()`. See the [design](design.md#celery).

Stories wait until the owner schedules the feature. Do not start or elaborate it
before then.
