**Outcome:** `rn-forge-devops index` wrote a PEP 503 index of the release files
and the docs job published it on 2026-10-25. The self-hosted index was retired
when packages moved to PyPI
([F21.5](../E21-pypi-distribution/F21.5-retire-index.md)).

## Design

The index writer, its release adapter, the composite action and the consumer
guide were built as one design that no longer exists in the repository. Consumer
install instructions are in the
[consuming guide](../../../guides/consuming-packages.md).
