Removed 2026-11-13 (owner decision): S16.3.4 moved `plan` and `sonar-target` out
of `rn-forge-devops` into kiln's `kiln-devops`, so pykit owns no planner output
to remove. Whether `plan` drops an output is kiln's decision
([ADR-0008](../../../adr/ADR-0008.md)). The readers found on 2026-11-13 are
recorded under S16.6.1.

kiln's generated `ci.yml` reads only six of the twelve `rn-forge-devops plan`
outputs. This feature settles, once pykit runs on that workflow, whether the
other six and the `sonar-target` subcommand stay or go.

## Context

**Outcome:** the feature waited for the cutover ([F16.3](F16.3-cutover.md)),
because pykit's own `main.yml` read the coverage and Sonar outputs and
`sonar-target` until then, and a removal was a major bump of `rn-forge-devops`
that kiln had to match.

## S16.6.1 — Retire the outputs generated CI does not read

**State:** Removed · **Depends on:** S16.3.2

Revisit the [open question](#open-questions) once pykit runs on kiln's generated
CI, with `main.yml` gone.

**Outcome:** on 2026-11-13 generated `ci.yml` read `release-order`, `packages`,
`integration`, `smoke`, `suites`, `pytest-args` and `docs`, and `sonar-target`
through `task ci:sonar:target`; the coverage and Sonar outputs were read only by
`.github/scripts/sonar_local.py`, which S16.8.1 deleted, and kiln S6.10.1
retired them from `plan()`. No other rn-forge repository runs the planner.

**Acceptance:**

- The decision is recorded, and the open question is removed from this feature.
- If any output was removed: `uv run pytest packages/rn-forge-devops` passes,
  the outputs page lists exactly the keys `plan` returns, and the tag
  `rn-forge-devops-v1.0.0` exists with a published GitHub Release.

## Acceptance

```bash
set -euo pipefail
uv run pytest packages/rn-forge-devops          # S16.6.1, if any output was removed
git ls-remote --exit-code --tags origin rn-forge-devops-v1.0.0   # S16.6.1, if any output was removed
```

Not scripted: S16.6.1's decision, and the 1.0.0 release when outputs are
removed. If none are, neither command applies.

## Open questions

None. The feature is removed; the question passes to kiln.
