pykit keeps `.github/scripts/sonar_local.py` because kiln had no local Sonar
scan when F16.3 cut over. kiln F6.10 adds one: a `task` verb backed by a
`kiln-devops` subcommand. Once pykit adopts the kiln release that carries it,
the script, its tests and their configuration go away.

## Context

**Outcome:** the script was the only reader of the planner's `cov-args`,
`test-paths`, `sonar-sources` and `sonar-tests`; kiln's work did not gate this
feature ([ADR-0008](../../../adr/ADR-0008.md)).

## S16.8.1 — Use kiln's verb and delete the script

**State:** Closed (2026-11-13)

**Outcome:** the script and its tests are gone, and the development guide's
[Sonar feedback](../../../guides/development.md#sonar-feedback) section runs
kiln's verb instead.

**Acceptance:**

- `.github/scripts/sonar_local.py` does not exist, and no file outside
  `docs/specs/` names it.
- The kiln verb's dry run prints a target and both commands.
- `task kiln:diff` is clean, and `task validate` passes.

**Outcome:** `[kiln] ref` stayed `feature/v1`, which carries F6.10; the verb is
`task sonar:local`. Its dry run matched the script's documented behaviour, and
the owner's full scan on 2026-11-13 reached the SonarCloud plan limit that the
[`sonar-branch-analysis-plan` idea](../../ideas/index.md#sonar-branch-analysis-plan)
records.

## Acceptance

```bash
set -euo pipefail
test ! -e .github/scripts/sonar_local.py
! rg -q --hidden --glob '!.git' --glob '!docs/specs/**' 'sonar_local'
task kiln:diff
task validate
```

Not scripted: the dry-run comparison, and a full scan with a real `SONAR_TOKEN`.
