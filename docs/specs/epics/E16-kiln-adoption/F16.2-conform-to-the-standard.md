kiln built a repository from a fresh `python-lib` skeleton carrying pykit's
packages, and ran the gate every kiln repository runs. Where pykit failed only
because it differs from the shared standard or from current tools, pykit
changes. Each story is something pykit should do whether or not it adopts kiln.

## Context

This feature runs first in Release 4. It rewrites lint sites and `__all__` lists
across every package, every `README.md` and `CHANGELOG.md`, and all Markdown.
[F15.2](../E15-package-boundaries/F15.2-auth-package.md),
[F15.3](../E15-package-boundaries/F15.3-data-package.md) and E13's
implementation features move the same files. Landing this first means the new
packages start lint-clean, mdformat-clean and in Keep a Changelog shape, and the
moves never rebase over a reformat.

The run used freshly resolved dev tools, which is what any `uv lock --upgrade`
or Dependabot bump gives pykit too: its floors (`ruff>=0.15.21`,
`pyright>=1.1.411`) do not stop newer versions. Kiln's findings that were kiln's
to fix (workspace members in the dependency contract, namespace packages, a
repository's own import contracts) are fixed in kiln and are not here.

## Stories

### S16.2.1 — The gate passes on current tools

**State:** Closed

With ruff 0.17 the gate fails with 177 errors: `PLE1205` (88, logging calls
whose arguments do not match the format string), `RUF022` (unsorted `__all__`),
`I001`, `UP035`, `UP037` and `BLE001`. With current `django-stubs`, pyright
reports four errors in `rn_forge/django/drf/utils.py`: `UploadedFile` needs type
arguments.

**Acceptance:**

- After
  `uv lock --upgrade-package ruff --upgrade-package pyright --upgrade-package django-stubs`,
  `uv run ruff check`, `uv run ruff format --check` and `uv run pyright`
  pass. Each `PLE1205` is a real fix or a per-line `noqa` with the reason (for
  example, a `verboselogs` method ruff cannot see); none is a blanket ignore.
- The floors in the root `dev` group are raised to the versions the lock now
  holds.

### S16.2.2 — Markdown is mdformat-clean

**State:** Closed

pykit's rn-forge docs standard ([ADR-0007](../../../adr/ADR-0007.md)) and kiln's
ADR-0012 format every Markdown file with mdformat. Fourteen files are not
formatted under the shared configuration, among them every package's `README.md`
and `CHANGELOG.md`.

pykit has no mdformat setup yet. Add, as kiln seeds them:

- to the root `docs` dependency group: `mdformat>=1.0.0`, `mdformat-gfm>=0.4`,
  `mdformat-front-matters>=2.0.0`, `mdformat-mkdocs>=5.3.0`;
- a root `.mdformat.toml`:

```toml
# Seeded by kiln — this file is yours.
#
# Its presence is what opts this repo into Markdown formatting at all: the
# task exists in every repo, the style is each repo's own. kiln writes this
# once and never touches it again.
#
# `exclude` is authoritative — `task lint` runs mdformat over the tree rather
# than over a file list, so this is the single place a path is exempted.
# `.rn-forge/kiln/standard.md` is not a style exemption: it is a file kiln owns
# whole (see .rn-forge/kiln/standard.md), and a formatter rewriting it would be
# a second owner writing the same bytes. Files kiln owns only a *block* of are
# formatted normally; kiln renders those block bodies already mdformat-clean.
wrap = 80
exclude = [
  ".venv/**",
  # Tool caches — the same set `task clean` removes and `.gitignore` ignores.
  # They carry third-party READMEs and licences, none of which are this repo's
  # prose. mdformat resolves its config per file, from that file's own
  # directory upward, so a nested repo's caches are that repo's to exempt.
  # `**/`: a task run with `--directory packages/<pkg>` runs the tool there, so
  # each workspace member grows its own caches.
  "**/.uv-cache/**",
  "**/.pytest_cache/**",
  "**/.ruff_cache/**",
  "**/.import_linter_cache/**",
  ".docs-site/**",
  "site/**",
  "node_modules/**",
  ".nx/**",
  ".rn-forge/kiln/rendered/**",
  # `kiln apply` keeps the managed files it replaced here.
  ".rn-forge/kiln/backups/**",
  ".rn-forge/kiln/standard.md",
]

[plugin.tables]
compact_tables = true

[plugin.mkdocs]
align_semantic_breaks_in_lists = true
ignore_missing_references = true
no_mkdocs_math = true
```

Then run `uv run --group docs mdformat .` once and review the diff.

**Acceptance:**

- `uv run --group docs mdformat --check .` passes.
- The strict docs builds still pass.

### S16.2.3 — Changelogs follow Keep a Changelog

**State:** Closed

`rn-forge-commons` and `rn-forge-django` end with `## Earlier releases`. In Keep
a Changelog every second-level heading is `## [Unreleased]` or
`## [<version>] - <date>`; the shared docs check rejects anything else.

**Acceptance:**

- No `CHANGELOG.md` has a second-level heading other than `[Unreleased]` or
  `[<version>] - YYYY-MM-DD`. The note about releases that predate the file is
  a paragraph under the oldest version, linking to the GitHub Releases page.

## Acceptance

- The gate passes on freshly resolved lint and type tools (S16.2.1).
- Every Markdown file is mdformat-clean (S16.2.2), and every changelog follows
  Keep a Changelog (S16.2.3).
- `uv run pytest`, `uv run lint-imports`, `uv run pyright` and
  `sh docs/_update_board.sh --check` pass.
