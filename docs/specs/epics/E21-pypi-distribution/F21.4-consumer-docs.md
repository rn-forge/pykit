# F21.4 — Consumers install from PyPI

|  |  |

Every page that tells a reader how to install a package describes PyPI. The
direct-URL form is kept as the alternative for pinning a tag. The pages are
written in the same release that first publishes to PyPI, so they are true when
it ships.

## Design

- **Root `README.md`**, *Installing a package*:
    - one example, `dependencies = ["rn-forge-commons>=0.7,<0.8"]`, with no index
      table;
    - the direct-URL form as the alternative.
- **`docs/guides/consuming-packages.md`**:
    - the intro says every package is published to PyPI;
    - remove *Declare the index*, *Use uv* and *The pip caveat*;
    - add *Moving off the pykit index*: delete the
      `[[tool.uv.index]] name = "rn-forge"` table, then run `uv lock`;
    - keep *Pin one exact version* and *Fall back to a direct URL*, the latter
      with a current tag.
- **Each `packages/<pkg>/README.md` and
  `packages/<pkg>/docs/guides/installation.md`**:
    - install by name and range, for example
      `uv add "rn-forge-django[all]>=0.5,<0.6"`, using the package's Release 7
      minor;
    - remove the git-URL examples, which name tags from earlier releases;
    - remove any mention of the pykit index.
- **`docs/runbooks/releasing-packages.md`**:
    - *How CI tags* describes the PyPI upload before the GitHub release, the skip
      when PyPI already has the version, the changelog notes, the `twine check`
      on every build, and the umbrella release;
    - the manual-dispatch paragraph adds the `testpypi` dry run;
    - new section *Yanking a bad version*: yank on pypi.org, then release the next
      patch;
    - the hand check of a resumed tag installs `"$package==$version"` from PyPI.

## Stories

### S21.4.1 — Install docs describe PyPI

**State:** New

**Acceptance:**

- No current page tells a reader to declare the pykit index or to install by git
  URL as the main route.
- The root site and every package site build with `--strict`.

## Acceptance

```bash
set -euo pipefail
absent() { local rc=0; rg -q --hidden --glob '!.git' "$@" </dev/null || rc=$?; [ "$rc" -eq 1 ]; }
absent 'github.io/pykit/simple' --glob '!consuming-packages.md' README.md packages/*/README.md packages/*/docs docs/guides docs/runbooks
absent 'tool.uv.index' README.md packages/*/README.md packages/*/docs docs/runbooks
uv run --group docs mkdocs build --strict -q
for d in packages/*/; do uv run --group docs mkdocs build --strict -q -f "$d/mkdocs.yml"; done
```

`docs/guides/consuming-packages.md` may still name the old index under *Moving
off the pykit index*, so the first check leaves it out.
