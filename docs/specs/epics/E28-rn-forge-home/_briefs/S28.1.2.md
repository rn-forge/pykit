# S28.1.2 — `doctor` reports the shell hookup

Brief for
[S28.1.2](../F28.1-home-contract-and-completions.md#s2812-doctor-reports-the-shell-hookup),
at `eae21ca0`. Paths are relative to `packages/rn-forge-tooling/` unless they
start with `docs/`.

## Goal

`doctor` tells a user whether their shell is hooked up to the rn-forge home:
whether `env.sh` exists, whether it is at the current schema, and whether
`$RNF_HOME/bin` is on `PATH`.

## Settled

- The three codes, their severities and meanings are the feature's
  [Design](../F28.1-home-contract-and-completions.md#rn-forge-tooling) table
  ([ADR-0017](../../../../adr/ADR-0017.md)). All three are `Severity.WARNING`.
- Reviewer, 2026-11-20:
    - `home.py` gains a public `env_schema(root: Path) -> int | None`: the schema
      number on `<root>/env.sh`'s first line, or `None` when the file is
      missing, empty, or its first line does not match `_SCHEMA_LINE`. Add it to
      `__all__`. `write_env` uses it in place of its own parsing
      (`home.py:90-96`), keeping its behaviour: missing → `WRITTEN`; present
      with `env_schema(...) is None` → `FOREIGN`; `>= ENV_SCHEMA` → `CURRENT`;
      lower → `WRITTEN`.
    - `lifecycle.py` gains `_home_findings(home: ToolHome) -> list[Finding]` in
      the `# -- doctor` section. `doctor` becomes
      `_install_findings(...) + _home_findings(home) + product checks`, so the
      home rows come after the install rows and before the product's checks, and
      they are reported whether or not the product is installed.
    - The rows, in this order:
        - `home.env-missing` when `not home.env_path.is_file()`: message
          `f"{home.env_path} does not exist; any install writes it"`,
          `path=str(home.env_path)`.
        - `home.env-stale` when `env_schema(home.root)` is an `int` below
          `ENV_SCHEMA`: message
          `f"{home.env_path} is at schema {n}, this version writes {ENV_SCHEMA}; any install rewrites it"`,
          `path=str(home.env_path)`,
          `details={"recorded": n, "expected": ENV_SCHEMA}`.
        - A foreign `env.sh` (present, no schema line) gives no row: it is the
          user's file.
        - `home.not-on-path` when `env_hint(home.root)` is not `None`: the message
          is that hint text, `path=str(home.root / "bin")`.
    - `install.ok` is unchanged: it still means "the install checks found nothing"
      and ignores the home rows.
