### S9.3.2 — Decide order enforcement

**Status:** planned

**Acceptance:** Owner records whether CI must enforce dependency-ordered publication.

## Current mechanism

On a push to `main`, `_package-ci.yml` can create a missing package tag and GitHub Release. The six package jobs in `main.yml` do not enforce a dependency-ordered chain. The release runbook records these facts; workflow changes require a separate task.

## Acceptance

- Release instructions match the workflow conditions and tag naming in the files.
- The owner decides whether CI needs an enforced dependency order and records the outcome before the tag cut.

## Open questions

Must CI enforce dependency-ordered publication, and what enforcement mechanism is required if so? Record the chosen policy before implementing affected publish jobs or cutting tags.
