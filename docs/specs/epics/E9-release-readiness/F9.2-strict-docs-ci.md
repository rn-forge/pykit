# F9.2 — Build documentation strictly in CI

**Status:** in progress · **Epic:** [E9](index.md)

**Depends on:** the root and seven package sites building cleanly with `--strict`, which they do today.

The CI `docs` job runs `uv run --group docs mkdocs build` without `--strict`, so a broken link or anchor passes CI. Locally, every site builds strictly.

## Stories

### S9.2.1 — Make the docs job strict

**Status:** in progress

**Acceptance:** the CI `docs` job runs MkDocs with `--strict`, and a pull request shows it passing.

The flag is set and the combined site builds strictly locally. The `docs` job runs only on a push to `main`, so it is confirmed by the first merge run.

```bash
set -euo pipefail
grep -q 'mkdocs build --strict' .github/workflows/main.yml
```
