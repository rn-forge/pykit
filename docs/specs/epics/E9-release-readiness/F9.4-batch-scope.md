Release-1 is pykit's first coordinated set of tags. Earlier single-package tags exist for `rn-forge-commons` and `rn-forge-django`, up to `v0.2.2`. This feature decides which packages and which unbuilt features it carries; it is a decision only, with no code change.

## Context

The [django split](../../ideas.md#django-optional-areas) was a soft dependency that did not block this decision, and stays parked.

## Stories

### S9.4.1 — Select the packages

**State:** Closed (2026-09-26)

**Acceptance:** the owner approves the packages and versions in release-1, and the [release-1 page](../../../releases/release-1/index.md) lists them with their delivered feature IDs.

### S9.4.2 — Decide the consumer-reuse features

**State:** Closed (2026-09-26)

**Acceptance:** the owner decides whether [F6.1](../E6-consumer-reuse/F6.1-log-redaction.md) and [F6.2](../E6-consumer-reuse/F6.2-sse.md) join release-1. Neither joins: both are `deferred` in [E6](../E6-consumer-reuse/index.md), with their IDs.

## Scope

All seven packages, at the versions their manifests declare (approved 2026-09-26). Direct internal prerequisites come from the manifests:

| Package | Declared version | Tag | Direct internal prerequisites |
| --- | --- | --- | --- |
| `rn-forge-commons` | `0.5.0` | `rn-forge-commons-v0.5.0` | None |
| `rn-forge-cli` | `0.1.0` | `rn-forge-cli-v0.1.0` | `rn-forge-commons` |
| `rn-forge-tooling` | `0.2.0` | `rn-forge-tooling-v0.2.0` | `rn-forge-commons`, `rn-forge-cli` |
| `rn-forge-web` | `0.1.0` | `rn-forge-web-v0.1.0` | `rn-forge-commons[pydantic]` |
| `rn-forge-django` | `0.3.0` | `rn-forge-django-v0.3.0` | `rn-forge-commons`, `rn-forge-web` |
| `rn-forge-fastapi` | `0.1.0` | `rn-forge-fastapi-v0.1.0` | `rn-forge-web[security]` |
| `rn-forge-sqlalchemy` | `0.1.0` | `rn-forge-sqlalchemy-v0.1.0` | `rn-forge-web` |

Optional extras add internal edges: `rn-forge-web[auth]` adds `rn-forge-commons[auth]`; Django's `fixtures` and `oidc` extras add commons capabilities, and its `oidc` and `security` extras add web capabilities; FastAPI's `oidc` extra adds `rn-forge-web[auth]` and its `transfer` extra adds `rn-forge-commons[excel]`. CLI and tooling are not prerequisites of web or the framework packages.

## Acceptance

- The owner approves the package and version list above, and the release-1 page lists them with their delivered feature IDs (S9.4.1).
- F6.1 and F6.2 are `deferred` in E6, with their IDs, and neither is on release-1's scope (S9.4.2).
