## Stories

### S9.6.1 — Approve and cut the tags

**Status:** planned

**Acceptance:**

- The owner approves the release and its package list.
- After the merge to `main`, every release-1 package's CI job succeeds, and its tag and GitHub Release exist.
- The release page records each tag and its commit.

```bash
set -euo pipefail
# PACKAGES holds release-1's "<package> <tag>" pairs, one per line.
while read -r pkg tag; do
  git ls-remote --exit-code --tags origin "refs/tags/$tag" >/dev/null
  gh release view "$tag" >/dev/null
done <<<"$PACKAGES"
```

Not scriptable: the owner's approval.
