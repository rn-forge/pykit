## Stories

### S9.5.1 — Verify remote refs and installs

**Status:** planned

**Acceptance:** Each selected package installs from its remote tag without workspace overrides.

## Acceptance

- Each selected tag exists on the remote.
- A clean external environment installs each package through its declared Git direct URL without workspace overrides.
- The release record names the tested refs and result.

Local workspace resolution cannot supply this evidence.
