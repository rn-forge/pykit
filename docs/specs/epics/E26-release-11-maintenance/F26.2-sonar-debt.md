## S26.2.1 — Fix the test findings

**State:** Closed (2026-11-19)

**Acceptance:**

- Each S5778 and S3415 issue's test is rewritten so the `pytest.raises` block
  holds the one call expected to raise, with arguments built before it, and
  the assertion names the actual value first.
- The tests assert the same things as before.
- `task validate` passes.

**Outcome:** 44 S5778 and 2 S3415 sites rewritten across 19 test files; the next
Sonar scan confirms them. The two `atomic_replace` tests in `test_paths.py` must
write through the entered temporary path inside the block, so Sonar may still
flag them.
