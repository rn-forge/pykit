## Goal

## Settled

- **S5778** ("Refactor this exception test to have only one invocation possibly
  throwing an exception"): Sonar counts every call inside a `pytest.raises`
  block, including calls that build arguments (`product(github)`,
  `_principal()`, a constructor). Build those before the block, bound to a
  local name, so the block holds exactly the one call expected to raise.
  Assertions on state after the raise stay after the block, outside it.
- When the "argument" call is itself what must raise (rare), keep it and move
  the other call out instead.
- **S3415** ("Swap these 2 operands so the actual value comes first"): put the
  actual value on the left of the comparison.
- Keep test names, parametrisation and `match=` patterns. No production code
  changes. No new helpers unless one is shared by three or more rewritten
  tests in the same file.
