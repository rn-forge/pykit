    - #25: `tablib[xlsx]>=3.10.0` (`rn-forge-data`).

      listed.

  predate Releases 9 and 10), apply the floor to the line as it is now; never
  lower a floor that is already higher.

  changes). Never edit `uv.lock` by hand. Afterwards the lock must resolve
  each package above at or above its floor; check with
  `grep -A1 'name = "<pkg>"' uv.lock`.

  version or adding a broad ignore. A fix that needs a suppression uses the
  narrowest rule with a reason, per the README comment rules.

  under `## [Unreleased]`, `### Changed`, in its `CHANGELOG.md` (e.g.
  "Requires `tablib[xlsx]>=3.10.0`."). Dependency-group-only changes
  (`[dependency-groups]`) are not published and get no line. Create the
  `[Unreleased]` heading in the file's existing format if it is missing.
