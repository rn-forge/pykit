## Settled

- **S3776 (1, 9, 10, 11, 13, 14):** extract private module-level or private
  method helpers (leading underscore) until each function is at or below 15.
  Behaviour, signatures and the order of side effects stay the same. A helper
  gets a docstring only if the README rules ask for one on private code.
- **S1192 (2–8):** one private module constant per literal (e.g.
  `_VALIDATION_ERROR = "Validation Error"`), used at every occurrence in that
  module. Do not share constants across modules. A literal that is part of a
  documented wire contract keeps its exact value.
- **12, 15, 16:** the mechanical fix Sonar names; for 16, the regex must match
  exactly what it matched before (`redaction.py` tests show it).
- **17 (S5886):** `dataclasses.replace` returns the type of its argument, and
  pyright strict already types the result as `Principal`; Sonar mis-infers it.
  Do not change the code. Record: key `AaHtIFshtunqNZ1Frc1C`, false positive,
  `dataclasses.replace` is generic in its argument.
- **18, 19 (S5754):** right code. `_main` hands a constructor's exception,
  `KeyboardInterrupt` and `SystemExit` included, to the waiting caller, and
  `_serve` delivers a job's exception to its future; re-raising would kill the
  actor thread and leave the caller waiting. Do not change the code. Record:
  keys `AaHW2efLUPDpoJKGF_V7` and `AaHW2efLUPDpoJKGF_V8`, won't fix, with that
  reason.
- **20 (S5655):** check the openpyxl stub for `Worksheet.add_table` against the

  `ignore` there, or a different `Table` class), fix it. If they match, do not
