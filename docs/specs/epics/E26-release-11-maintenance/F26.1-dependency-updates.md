## S26.1.1 — Take the Dependabot updates

**State:** Closed (2026-11-19)

**Acceptance:**

- Every update in the Context table is in the members' `pyproject.toml` files
  and in `uv.lock`, at the version the pull request names or later.
- The unnecessary `pyright: ignore` comments in `rn_forge/commons/testing.py`
  are removed, and any other check the bumps break is fixed in the code, not
  by pinning the old version.
- A change to a released package's runtime or extra requirement is in that
  package's `CHANGELOG.md` under its next version.
- `task validate` passes.

**Outcome:** locked at assertpy 2.36.1, asyncpg 0.32.0, import-linter 2.17,
mkdocs-material 9.8.2, pandas-stubs 3.1.0.261029, pytest 9.2.0, pytest-asyncio
1.5.0, pytest-django 4.14.0, ruff 0.17.6, types-authlib 1.8.0.20261106, tablib
3.10.0, pyjwt 2.15.1 and mkdocstrings 1.0.8. The only break was two unneeded
`pyright: ignore` comments in `rn_forge/commons/testing.py`.
