`MarkdownUtils`, in `rn_forge.commons.text.markdown` behind a `markdown` extra,
reads the structure of a Markdown document:

- its headings and the anchors a renderer gives them;
- its link and image targets;
- its title;
- its pipe tables, with their line positions;
- its text with fenced code removed.

A documentation checker, a notes or content application, and a generator that
fills a table in a page all need these.

## Context

kiln parses Markdown with regular expressions, plus Python-Markdown's `toc`
slugifier so anchors match MkDocs. Run against kiln's 119 pages on 2026-10-24,
a markdown-it-py token stream with the same slugifier produced the same
anchors on every page. Links differed on four pages, and in each case the
regular expression was wrong:

- It counted a link written inside inline code.
- It missed a link whose text contains brackets, such as
  ``[No deleted `[cli]` keys](#…)``.

markdown-it-py is CommonMark-compliant, maintained and already in commons'
environment through `rich`, so [ADR-0001](../../../adr/ADR-0001.md) rule 1
picks it over hand-written patterns.

## Design

**`packages/rn-forge-commons/pyproject.toml`**: extra
`markdown = ["markdown>=3.7", "markdown-it-py>=3.0"]`, and both added to `all`.

**`src/rn_forge/commons/text/markdown.py`** (new). The module docstring says
it parses with markdown-it-py (CommonMark plus GFM tables), and that anchors
follow Python-Markdown's `toc` extension, which MkDocs uses. The parser is one
module-level `MarkdownIt("commonmark").enable("table")`.

```python
@dataclass(frozen=True, slots=True)
class MarkdownHeading:
    level: int
    text: str        # plain text: inline markup dropped, code spans kept as text
    anchor: str      # unique within the document
    line: int        # 0-based line of the heading


@dataclass(frozen=True, slots=True)
class MarkdownTable:
    header: tuple[str, ...]
    rows: tuple[tuple[str, ...], ...]   # each row exactly len(header) cells
    start: int                          # 0-based line of the header row
    end: int                            # 0-based line after the last row


class MarkdownUtils:
    @staticmethod
    def slugify(text: str, separator: str = "-") -> str: ...
    @staticmethod
    def headings(text: str) -> list[MarkdownHeading]: ...
    @staticmethod
    def anchors(text: str) -> set[str]: ...
    @staticmethod
    def title(text: str) -> str | None: ...
    @staticmethod
    def links(text: str) -> list[str]: ...
    @staticmethod
    def is_external(link: str) -> bool: ...
    @staticmethod
    def tables(text: str) -> list[MarkdownTable]: ...
    @staticmethod
    def strip_fenced_code(text: str) -> str: ...
```

1. **`slugify`** is `markdown.extensions.toc.slugify(text.strip(), separator)`.
1. **`headings`** lists ATX and setext headings in document order, never one
   inside code. `text` joins the heading's inline `text` and `code_inline`
   children. `anchor` is `slugify(text)` made unique with
   `markdown.extensions.toc.unique`, which adds `_1`, `_2`, … to repeats.
   `line` is the heading token's `map[0]`.
1. **`anchors`** is the set of `headings(text)` anchors.
1. **`title`** is the `text` of the first level-1 heading, or `None`.
1. **`links`** lists, in document order, every `link_open` token's `href` and
   every `image` token's `src`, each passed through `urllib.parse.unquote`.
   This covers inline, reference and collapsed-reference links, and
   autolinks. A reference with no definition is not a link and yields nothing,
   and nothing inside code is a link.
1. **`is_external`** is
   `bool(urllib.parse.urlsplit(link).scheme) or link.startswith("//")`.
1. **`tables`** lists GFM pipe tables in document order, never one inside code.
   Each cell is its inline token's `content`, stripped; header cells may be
   empty. `start` and `end` are the `table_open` token's `map`.
1. **`strip_fenced_code`** returns the text with every line of every `fence`
   token's `map` removed.

**Import boundaries**: none to add. [F18.1](F18.1-template-engine-in-commons.md)'s
`commons-core-has-no-extras` contract already forbids `rn_forge.commons.text`,
`markdown` and `markdown_it` to commons' core. Its facade test already asserts
that `import rn_forge.commons` loads none of them.

**Docs**: `docs/reference/text/markdown.md` holding
`::: rn_forge.commons.text.markdown`, added under the `Text` reference group.
A `## Markdown` section in `docs/guides/text.md` shows the extra's install
line, then `anchors`, `links`, filtered with `is_external`, and `tables` on a
short page. The installation guide's extras table gets a `markdown` row.

**Changelog** (commons, `[Unreleased]`, *Added*): `rn_forge.commons.text.markdown`
(`MarkdownUtils`, `MarkdownHeading`, `MarkdownTable`) and the `markdown`
extra.

**Tests**: `tests/text/test_markdown.py`:

- `slugify("Hello, World!") == "hello-world"`.
- `headings`: repeated headings get `a`, then `a_1`; a `#` line inside a fence
  is no heading; a setext heading counts; ``# Use `foo` here`` has anchor
  `use-foo-here`; `line` is right.
- `title`: the first H1; `None` with no H1; an H1 inside a fence is ignored.
- `links`:
  - inline, reference, case-insensitive reference label, collapsed reference,
    image and autolink targets, in order;
  - a link inside inline code or a fence is ignored;
  - link text with brackets is found;
  - an undefined reference yields nothing;
  - `a%20b.md` comes back as `a b.md`.
- `is_external`: `https://x`, `mailto:a@b` and `//cdn/x.js` are external;
  `../a.md#x` and `#anchor` are not.
- `tables`:
  - two tables, with `start` and `end`;
  - a table inside a fence is ignored;
  - cells are stripped;
  - a short row is padded to the header's width;
  - a `| | |` header with `**Key**` rows parses.
- `strip_fenced_code`: removes backtick and tilde fences, including one closed
  by a longer fence, and keeps the text around them.

## Considered and rejected

- **Python-Markdown alone.** Its `toc` extension gives exact anchors, but it
  exposes no link or table structure without rendering HTML and parsing that
  back.
- **Regular expressions.** They miss links in bracketed text, and find links in
  code; markdown-it-py is CommonMark-compliant and already installed.
- **markdown-it-py's own slugifier** (`mdit-py-plugins` anchors). Its anchors
  differ from MkDocs' for punctuation and Unicode, and checking a MkDocs site is
  the first use.
