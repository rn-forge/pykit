A generator describes its artifacts as a table of path, ownership, template and
condition, and the generation engine renders them. It does not write
`Artifact(path, kind, engine.render(template, context))` once per file. A
preview, whether a CLI's `diff` command or a web page's "what will change"
screen, asks the engine for a unified diff of each planned change, instead of
reimplementing how the engine reads a file or a block body from disk.

## Context

kiln renders about twenty-five artifacts across eight modules. Each module
builds `Artifact`s by hand around `engine.render`, and switches files on or off
in its own way. kiln's `diff` command also carries a line-for-line copy of the
engine's private `_disk_content`.

## Design

**`packages/rn-forge-commons/src/rn_forge/commons/generation/templated.py`**
(new). It needs the `templates` extra. The `generation` facade does **not**
re-export it, so `import rn_forge.commons.generation` loads no Jinja. It is
imported as
`from rn_forge.commons.generation.templated import TemplateArtifact, render_artifacts`.
It is the one module that F18.1's `generation-core-renders-nothing` contract
leaves free to import `rn_forge.commons.text`.

```python
"""Artifacts rendered from Jinja templates."""

@dataclass(frozen=True, slots=True)
class TemplateArtifact:
    """One artifact to render: its path, its ownership and its template.

    Args:
        path: Repo-relative path of the rendered artifact.
        kind: Who owns its bytes; see ArtifactKind.
        template: Template name; ``None`` means ``f"{path}.j2"``.
        block: The fenced block, for an ArtifactKind.BLOCK artifact.
        enabled: ``False`` leaves the artifact out.
        context: Replaces the shared context for this artifact alone.
    """

    path: str
    kind: ArtifactKind = ArtifactKind.MANAGED
    template: str | None = None
    block: ManagedBlock | None = None
    enabled: bool = True
    context: Mapping[str, object] | None = None


def render_artifacts(
    engine: TemplateEngine,
    context: Mapping[str, object],
    artifacts: Iterable[TemplateArtifact],
) -> list[Artifact]:
    """Render each enabled artifact, in order.

    Raises:
        RenderError: A template failed; the message starts with the artifact's path.
        ValueError: From Artifact, when ``block`` does not match ``kind``.
    """
```

For each enabled entry, it renders `template or f"{path}.j2"` with the entry's
`context` when that is not `None`, else the shared `context`. It returns
`Artifact(path, kind, content, block=block)`. It re-raises a `RenderError` as
`RenderError("{}: {}", path, exc)` from the original.

**`generation/plan.py`**: rename `_disk_content` to `disk_content`, unchanged,
and add after it:

```python
def diff(root: Path, change: Change) -> str:
    """A unified diff from *change*'s content on disk to its rendered content.

    A block diffs its body; a missing file diffs from empty. Returns ``""``
    when the change has no artifact or nothing differs.
    """
```

It builds the diff with `difflib.unified_diff` over `splitlines(keepends=True)`
of the disk text (`""` when `None`) and `artifact.content`, with
`fromfile=tofile=artifact.path`. It returns `"".join(...)`. Add `diff` and
`disk_content` to `plan.__all__` and to the `generation` facade's imports and
`__all__`.

## Considered and rejected

- **`render_artifacts` as a `TemplateEngine` method.** It would put
  `generation`'s vocabulary into `text`, and give the engine a dependency on
  the generation package for one convenience.
- **Rendering a whole template directory** (every `*.j2` under a prefix, `.j2`
  stripped). kiln's generators choose files per archetype, so a directory walk
  would still need the same table of conditions.
- **Filtering seeded artifacts inside `diff`.** Whether a preview shows seeded
  files is a caller's policy; `diff` reports what differs.
