# S30.1.2 — create_postgres_engine

Brief for
[S30.1.2](../F30.1-postgresql-engine-and-driver-extras.md#s3012-create_postgres_engine),
at the S30.1.1 merge on `feature/release-12`. Read the feature's Design first;
the signature there is settled.

## Goal

`rn_forge.sqlalchemy.postgres.create_postgres_engine` builds an `asyncpg`
`AsyncEngine` with UTC sessions, optional server settings, pool arguments and
the prepared-statement cache size, and is exported from the package root.

## Settled

- New module `packages/rn-forge-sqlalchemy/src/rn_forge/sqlalchemy/postgres.py`,
  modelled on `sqlite.py`: module docstring,
  `__all__ = ["create_postgres_engine"]`, and a Google-style docstring with
  `Args:`, `Returns:` and `Raises:`.
- Signature exactly as in the feature's Design.
- URL: `sqlalchemy.engine.make_url(url)` (accepts `str` or `URL`). Accepted
  `drivername` values are `postgresql`, `postgres` and `postgresql+asyncpg`;
  the result is `url.set(drivername="postgresql+asyncpg")`. Anything else
  raises `ValueError` whose message names the drivername as given, e.g.
  `"create_postgres_engine needs a postgresql:// URL, got 'sqlite'"`.
- Numbers: `pool_size`, `max_overflow`, `pool_recycle_s`,
  `prepared_statement_cache_size` and, when given, `statement_timeout_ms` must
  be `>= 0`; a negative value raises `ValueError` naming the argument.
  Validate before building the engine.
- Connection arguments, all through
  `create_async_engine(..., connect_args=...)`:
    - `server_settings`: always `{"timezone": "UTC"}`; plus
      `"application_name": application_name` when it is not `None`, and
      `"statement_timeout": str(statement_timeout_ms)` when it is not `None`.
      asyncpg needs string values.
    - `prepared_statement_cache_size`: SQLAlchemy's asyncpg dialect reads it as a
      DBAPI connect argument (see `sqlalchemy/dialects/postgresql/asyncpg.py`,
      `AsyncAdapt_asyncpg_dbapi.connect`), not as a `create_async_engine`
      keyword. Pass it in `connect_args`.
    - `statement_cache_size`: asyncpg's own cache, the same value, in
      `connect_args`.
- Pool: `pool_size`, `max_overflow`, `pool_pre_ping` and
  `pool_recycle=pool_recycle_s` go to `create_async_engine`.
- It creates no tables and does not connect. Do not import `asyncpg` at module
  level (S30.1.3 adds the missing-driver error; this story does not).
- Export from `rn_forge/sqlalchemy/__init__.py` (import and `__all__`, kept
  sorted). The README's module table gains a `postgres` row next to `sqlite`,
  in the same style: "`create_postgres_engine` — an async PostgreSQL engine
  (asyncpg) with UTC sessions, pool settings and an optional statement timeout
  and application name". `CHANGELOG.md` `[Unreleased]` `### Added` names
  `create_postgres_engine`.

## Current behaviour

`rn_forge.sqlalchemy.postgres` does not exist, so every new test fails at import
with `ModuleNotFoundError: No module named 'rn_forge.sqlalchemy.postgres'` (or
`ImportError` on `from rn_forge.sqlalchemy import create_postgres_engine`).

## Change

1. Tests first, below; confirm they fail at import.
1. `postgres.py`, the export, README and changelog.

## Tests first

New file `packages/rn-forge-sqlalchemy/tests/test_postgres.py`,
`pytestmark = pytest.mark.unit` except the last test, `assertpy` style as in
`test_sqlite.py`; dispose every engine the test creates (a fixture like
`make_engine` there).

To see the connection arguments without a server, register a `do_connect`
listener on `engine.sync_engine` that records `cparams` and raises a sentinel
exception, then `await` a connect and catch it (SQLAlchemy may wrap it; assert
on the recorded `cparams`, not on the exception type). Read pool settings from
`engine.pool` (`size()`, `_max_overflow`, `_pre_ping`, `_recycle`).

- `test_create_postgres_engine_rewrites_accepted_schemes` (parametrized on
  `postgresql://`, `postgres://`, `postgresql+asyncpg://`):
  `engine.url.drivername` is `postgresql+asyncpg`.
- `test_create_postgres_engine_rejects_other_schemes` (parametrized on
  `postgresql+psycopg://u@h/d` and `sqlite:///x.db`): `ValueError` whose
  message contains `postgresql+psycopg` or `sqlite` respectively.
- `test_create_postgres_engine_sets_utc_timezone_server_setting`: with no
  optional arguments, `cparams["server_settings"] == {"timezone": "UTC"}`.
- `test_create_postgres_engine_adds_optional_server_settings_only_when_given`:
  with `application_name="svc"` and `statement_timeout_ms=1500`, the settings
  also hold `application_name="svc"` and `statement_timeout="1500"`.
- `test_create_postgres_engine_passes_pool_arguments`: non-default values reach
  `engine.pool`.
- `test_create_postgres_engine_passes_prepared_statement_cache_size`
  (parametrized on 0 and 25): `cparams` holds both
  `prepared_statement_cache_size` and `statement_cache_size` at that value.
- `test_create_postgres_engine_rejects_negative_arguments` (parametrized over
  each numeric argument at `-1`): `ValueError` naming the argument.
- `test_create_postgres_engine_connection_reports_utc`, marked
  `pytest.mark.postgres`: skips without `RN_FORGE_TEST_POSTGRES_DSN` (use the
  `POSTGRES_DSN` constant in `tests/conftest.py`). With it, passes the bare
  `postgresql://` DSN straight to
  `create_postgres_engine(..., application_name="rn-forge-test")`, and on a
  connection `SHOW timezone` is `UTC` and
  `SELECT current_setting('application_name')` is `rn-forge-test`.
