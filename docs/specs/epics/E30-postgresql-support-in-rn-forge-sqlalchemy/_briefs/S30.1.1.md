# S30.1.1 — Driver extras

Brief for
[S30.1.1](../F30.1-postgresql-engine-and-driver-extras.md#s3011-driver-extras),
at `afb8d5f5` plus S29.1.2. Read the feature's Design first.

## Goal

`rn-forge-sqlalchemy` declares `postgres` and `sqlite` extras that bring in the
drivers, and its README and comment say so.

## Settled

- `packages/rn-forge-sqlalchemy/pyproject.toml`,
  `[project.optional-dependencies]`: add `postgres = ["asyncpg>=0.32.0"]` and
  `sqlite = ["aiosqlite>=0.22.1"]` alongside `migrations`. The floors are the
  versions `uv.lock` resolves today.
- The comment above `dependencies` replaces "No database driver is declared: the
  application picks one (`asyncpg`, `aiosqlite`)." with a line saying the
  drivers come from the `postgres` and `sqlite` extras, so the core install
  carries none. Keep the `rn-forge-commons` sentence.
- The `dev` dependency group's `aiosqlite>=0.21` and `asyncpg>=0.32.0` stay as
  they are.
- `packages/rn-forge-sqlalchemy/README.md`: replace "No database driver is
  declared. Add `asyncpg` for PostgreSQL or `aiosqlite` for SQLite." with the
  extras: `rn-forge-sqlalchemy[postgres]` installs `asyncpg`,
  `rn-forge-sqlalchemy[sqlite]` installs `aiosqlite`, and the core install
  carries no driver. Match the install-line style of the `migrations` sentence
  below it (`rn-forge-sqlalchemy[postgres]>=0.2.5,<0.3`).
- `packages/rn-forge-sqlalchemy/CHANGELOG.md`: under `## [Unreleased]`,
  `### Added`: "The `postgres` and `sqlite` extras install `asyncpg` and
  `aiosqlite`." Do not bump the version; S30.1.3 does that.
- `uv.lock` is regenerated by `task setup`; never edit it by hand.

## Current behaviour

At `afb8d5f5`,
`importlib.metadata.metadata("rn-forge-sqlalchemy").get_all("Provides-Extra")`
is `['migrations']`, so a test asserting `postgres` and `sqlite` are in it fails
on the assertion.

## Change

1. The test, below; confirm it fails.
1. `pyproject.toml`, then `task setup` so the editable install's metadata lists
   the new extras.
1. README and changelog.

## Tests first

New file `packages/rn-forge-sqlalchemy/tests/test_package.py`, marked
`pytestmark = pytest.mark.unit`, in the style of the package's other tests
(`assertpy`):

- `test_package_metadata_lists_postgres_and_sqlite_extras`: reads
  `importlib.metadata.metadata("rn-forge-sqlalchemy")`, asserts
  `Provides-Extra` contains `postgres` and `sqlite`, and that `Requires-Dist`
  has an `asyncpg` entry with `extra == "postgres"` and an `aiosqlite` entry
  with `extra == "sqlite"`.
