# ADR-0007: Package usage docs and monorepo governance have separate homes

This decision routes documentation for package users and workspace maintainers. It guides contributors adding or moving documentation pages.

**Status:** accepted

**Recorded:** 2026-09-24

**Scope:** Root and package documentation

## Decision

Keep package usage, guides, API reference, and executable examples with the package that owns them. Keep cross-package architecture, contributor guides, runbooks, release evidence, specifications, decisions, and historical plans under root `docs/`. The root MkDocs site includes all seven package sites; each package site remains independently buildable.

The spec board owns live work status. The plans area preserves dated source material and a migration ledger. Internal links move to the new homes. A known external handoff path may keep a forwarding page. Root navigation remains explicit.

## Consequences

An installed-package user can find its contract without reading monorepo governance. Maintainers can follow a live work item to its owning epic and historical source. Raw plans remain repository evidence rather than current product guidance.

## Influences

This decision shapes [E10 documentation refactor](../specs/epics/E10-documentation-refactor/index.md), the [root documentation index](../index.md), and the [migration ledger](../plans/context.md).

## Alternatives considered

Moving every package `api/` and web `adoption/` page into root taxonomy would break the package ownership and standalone-site model. Adopting kiln's full generated navigation now would expand this content migration into a tooling cutover. Preserving every historical URL would keep obsolete pages prominent without a known consumer need.

## Background

`docs-structure-review.md`, “Proposed target tree,” “Package-by-package disposition,” and Q1–Q3/Q8 supplied the proposal. The owner accepted those defaults on 2026-09-24. The [migration ledger](../plans/context.md) records original paths and destinations. Release scope and behavior questions Q4/Q5/Q9/Q10 remain with their owning work, outside this routing decision.
