# Releases

This area records coordinated package release batches for maintainers. Each package keeps its own version and tag.

**Status:** planned

**Readiness:** not ready

**Owner:** pykit release owner.

The [proposed release-1 batch](release-1/index.md) is the first coordinated batch documented by this structure. It is not pykit's first-ever release: historical commons and Django tags exist. No package has been assigned to this batch yet. [F9.4](../specs/epics/E9-release-readiness/F9.4-batch-scope.md) holds the owner's package-scope decision.

The [release runbook](../runbooks/releasing-packages.md) describes the current workflow. [E9](../specs/epics/E9-release-readiness/index.md) tracks readiness and approval evidence.

Release-1 is flagged **not ready**: its required decision specs are unsettled. The release page distinguishes blocking gates from unassigned candidate features.
