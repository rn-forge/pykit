## Breaking changes

None. F14.4 changed package source in six packages (commons, django, fastapi, sqlalchemy, tooling, web), but no public signature or documented behavior changed. The one behavior change: Django's `SequenceGenerator` revalidates `name` and quotes it with `connection.ops.quote_name` before each PostgreSQL statement, so a `name` reassigned to an unsafe value now raises `AppException` before any SQL runs. The rest is refactors (helper extraction, PEP 695 generics, module constants, `asyncio.timeout` in the private `_run_bounded`, a sync private FastAPI catalog handler). No version changed, so none of it is published yet; it ships with each package's next version bump.
