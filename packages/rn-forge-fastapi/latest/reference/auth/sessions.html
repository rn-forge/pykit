    Auth sessions¶

    The login session and the middleware that resolves it.

    rn_forge.fastapi.auth.sessions ¶

    The login session, kept in an rn-forge-auth :class:~rn_forge.auth.SessionStore.

    The session ID travels in the __Host-session cookie. Every store call is synchronous; :class:Sessions methods are blocking and async code runs them in the thread pool. :class:SessionMiddleware resolves the session once per request and keeps its cookie current.

    GET requests to the paths in untouched_paths read the session without extending it; every other request moves the idle expiry forward.

    The middleware also runs the :class:~rn_forge.fastapi.auth.csrf.CsrfProtection check on an unsafe request that carries the session cookie, or that goes to the password-login path, so the application's own session-authenticated routes are protected as well as the /auth routes. A request with no session cookie reaches the application unchecked.

    SessionMiddleware(app, *, sessions, untouched_paths=('/auth/session',), login_path='/auth/login/password', csrf_exempt_prefixes=('/auth/backchannel-logout/',)) ¶

    Resolve the login session once per request and keep its cookie current.

    The session is available through :func:active_session. Every request except a GET to untouched_paths extends the idle expiry and refreshes the cookie's Max-Age; a request whose cookie names no valid session or anonymous session gets the cookie cleared, unless its response sets the cookie itself.

    An unsafe request is then checked with sessions.csrf when it carries the session cookie, whether it names a live session, a live anonymous session or nothing known, or when its path is login_path, which a browser can reach with no cookie. A failure is answered with the 403 csrf-failed problem. A request to a path under csrf_exempt_prefixes is not checked.

    Name Type Description Default
    app ASGIApp

    The wrapped ASGI application.

    		 required
    sessions Sessions

    Reads and extends the sessions.

    		 required

    rotate_session(request) async ¶

    Give the request's session a new ID and keep its content.

    Call it after a change of the account's privileges, so a session ID that was seen before the change is useless afterwards. The middleware sets the new cookie on the response. A request with no session is left alone.

    Raises:

    Type Description
    RuntimeError

    :class:SessionMiddleware is not installed.
