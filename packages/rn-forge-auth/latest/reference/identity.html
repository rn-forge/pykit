    Identity¶

    rn_forge.auth.identity ¶

    Identity-provider contract and the values it exchanges.

    A provider takes the framework's native request and returns an :class:ExternalIdentity; everything on the far side of that result is framework-neutral.

    ProviderKind = Literal['oidc', 'oauth2', 'password', 'development'] module-attribute ¶

    The protocol family of an :class:IdentityProvider.

    ExternalIdentity(provider, issuer, subject, email=None, email_verified=False, name=None, picture=None, groups=frozenset(), attributes=dict[str, Any](), auth_time=None, amr=frozenset(), session_ref=None, id_token=None) dataclass ¶

    A verified identity asserted by a login provider.

    Attributes:

    Name Type Description
    provider str

    Configured provider ID.
    issuer str

    The OIDC iss, or "local" for a local login.
    subject str

    The OIDC sub.
    email str | None

    The email address, if the provider released one.
    email_verified bool

    Whether the provider verified email.
    name str | None

    Display name.
    picture str | None

    Avatar URL.
    groups frozenset[str]

    Group names the provider asserted.
    attributes Mapping[str, Any]

    Other mapped claims.
    auth_time datetime | None

    When the user authenticated.
    amr frozenset[str]

    How the user authenticated, such as pwd, mfa or hwk.
    session_ref str | None

    The OIDC sid, used for logout.
    id_token str | None

    The raw ID token, set only when the provider has RP-initiated logout enabled.
