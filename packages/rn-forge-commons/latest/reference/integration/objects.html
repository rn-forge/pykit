    Objects¶

    rn_forge.commons.integration.objects ¶

    Object-storage protocols: put/get/delete/exists plus a pre-signed URL.

    url_for returns a time-limited pre-signed URL (a SAS URL on Azure, a presigned URL on S3) so a client downloads directly instead of streaming bytes through the application. expires_in is required, not defaulted — a pre-signed URL with a forgotten expiry is a leak with a long tail.

    AsyncObjectStore ¶

    Bases: Protocol

    The async counterpart of :class:ObjectStore.

    Delete the object at key. A no-op when key does not exist.

    Return whether an object exists at key.

    Return the bytes stored at key.

    Type Description
    ObjectNotFound

    Store data at key, overwriting any existing object.

    url_for(key, *, expires_in) async ¶

    Return a time-limited pre-signed URL for key, valid for expires_in.
