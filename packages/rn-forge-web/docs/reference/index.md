# API Reference

The API reference is generated from source docstrings with `mkdocstrings`.

Start with [tracing](tracing.md) and [problem responses](problem.md) for the
shared HTTP contract. The remaining pages cover errors, concurrency,
pagination, operations, idempotency, health, OpenAPI naming, ASGI, and auth.
The [conformance table](conformance.md) is exercised by both framework adapters.
