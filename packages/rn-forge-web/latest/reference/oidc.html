    OIDC¶

    Requires the auth extra:

    uv add "rn-forge-web[auth]"

    rn_forge.web.oidc is not re-exported from rn_forge.web — import it directly:

    from rn_forge.web.oidc import OidcAuthenticator

    rn_forge.web.oidc ¶

    The OIDC bearer authenticator both framework bindings share.

    Joins the two halves of the auth story: rn-forge-commons verifies a token and returns claims, :mod:rn_forge.web.auth says what a caller is and what a refusal looks like. This module is the one implementation that connects them, so a Django service and a FastAPI service accept the same tokens and produce the same :class:~rn_forge.web.auth.Principal.

    Requires the auth extra (rn-forge-commons[auth], which brings PyJWT). Not imported by rn_forge.web's curated __init__.py; import this module directly.

    OidcAuthenticator(verifier, *, claims_to_principal=principal_from_claims) ¶

    An :class:~rn_forge.web.auth.Authenticator backed by a :class:JwtVerifier.

    Build one at startup and reuse it: the verifier holds the JWKS cache, so a per-request instance refetches the key set on every call.

    The reason a token was rejected is carried on the raised :class:~rn_forge.web.exceptions.AuthenticationFailed for the binding to log. It never reaches the response body — both framework packages render a 401 with :data:~rn_forge.web.auth.AUTH_FAILED_DETAIL.

    Parameters:

    Name Type Description Default
    verifier JwtVerifier

    Verifies the bearer token and returns its claims.

    		 required
    claims_to_principal ClaimsToPrincipal

    Verified claims → principal. Defaults to :func:~rn_forge.web.auth.principal_from_claims; override it for an IdP whose roles or scopes sit somewhere non-standard.

    		 principal_from_claims

    from_issuer(issuer, *, audience, claims_to_principal=principal_from_claims, fetch=fetch_json, algorithms=('RS256',), leeway=0.0, max_age=86400.0) classmethod ¶

    Build an authenticator by OIDC discovery on issuer.

    Discovery runs once, here — so call this at startup, not per request.
