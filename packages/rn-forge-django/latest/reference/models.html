    Concurrency and immutability¶

    rn_forge.django.models.concurrency ¶

    Opt-in optimistic-concurrency and immutability model mixins.

    ImmutableModelMixin ¶

    Bases: Model

    Abstract mixin that rejects post-creation mutation and deletion.

    Saving a changed row raises :class:rn_forge.web.DomainConflict; deleting always raises. Queryset-level update() and delete() bypass the guard.

    delete(using=None, keep_parents=False) ¶

    Always raise: an immutable row is never deleted.

    save(*, force_insert=False, force_update=False, using=None, update_fields=None) ¶

    Reject a change to any guarded field, then delegate to super().save().

    VersionedModelMixin ¶

    Bases: Model

    Abstract mixin adding an optimistic-concurrency version counter.

    Existing rows increment from the loaded version, including partial saves. A concurrent update raises :class:rn_forge.web.VersionConflict.

    save(*, force_insert=False, force_update=False, using=None, update_fields=None) ¶

    Bump version on update, then delegate to super().save().

    Allocate gap-free, human-readable codes from a named database sequence.

    Parameters:

    Name Type Description Default
    name str

    The sequence name. Must match [a-z][a-z0-9_]* (at most 63 characters): a sequence name cannot be a bound query parameter, so this validation is the only thing between the name and the DDL.

    		 required
    counter_model type[AbstractSequenceCounter]

    The consumer's concrete :class:AbstractSequenceCounter.

    		 required
    prefix str

    Passed to formatter.

    		 ''
    formatter Callable[[str, int], str] | None

    (prefix, value) -> code. Defaults to :func:default_code_formatter.

    		 None
    using str | None

    A database alias. Defaults to the router's write database for counter_model.

    		 None

    Raises:

    Type Description

    Cache¶

    rn_forge.django.models.cache ¶

    Caching helpers for model instance lookup.

    ModelLookupCache() ¶

    Bulk-load model instances for in-memory lookup by selected fields.

    Typical use: load a reference table once at startup, then resolve foreign-key values in O(1) rather than issuing per-row queries.

    Example::

    cache = ModelLookupCache()
cache.load(Country, "iso_code")
country = cache.get(Country, "AU")

    get(model_class, *model_key_values) ¶

    Return the cached instance matching model_key_values, or None.

    load(model_class, *model_keys) ¶

    Bulk-load all instances of model_class and index by model_keys.

    set(model_class, instance, *model_keys) ¶

    Insert or update instance in the cache.

    Utils¶

    rn_forge.django.models.utils ¶

    Model serialization helpers for rn-forge-django.

    ModelUtils ¶

    Utilities for serialising Django model instances.

    All methods are static.

    as_dict(instance, _seen=None) staticmethod ¶

    Return a plain dict of all concrete fields on instance.

    Related model instances are recursively converted. Cycles are broken by tracking id() of visited instances; a repeated instance is represented as its string repr instead of being expanded again.

    as_json_value(value) staticmethod ¶

    Coerce a model field value to a JSON-safe primitive.

    • Primitives (str, int, float, bool, None) are returned unchanged.
    • :class:~datetime.datetime, :class:~datetime.date, and :class:~datetime.time values are converted via .isoformat().
    • All other types fall back to str(value).
