    Transfer¶

    Requires the transfer extra; see the Transfer guide.

    rn_forge.django.drf.transfer ¶

    Tabular export and import, and batch create and delete, for DRF viewsets.

    Requires the transfer extra. Not re-exported by :mod:rn_forge.django.drf. Register the viewset with :class:~rn_forge.django.drf.routers.CustomMethodRouter so the actions are served as /orders:import and /orders:batchCreate.

    BatchCreateMixin ¶

    Bases: GenericAPIView

    Add POST :batchCreate: {"requests": [...]}, all or nothing.

    Each item goes through the view's serializer. The response is 200 with the created resources under the plural resource name. A validation failure is a 422 problem with errors[].pointer = "/requests/<i>/<field>"; an error string from :meth:validate_batch_create_item is a 403 problem pointing at the item. Nothing is persisted on failure.

    Attributes:

    Name Type Description
    batch_resource_name str | None

    The response key; the model's plural verbose name in camelCase when unset.

    prepare_batch_create_item(item) ¶

    Return one request item before serializer validation.

    validate_batch_create_item(item) ¶

    Return an error message for one validated item, or None when allowed.

    BatchDeleteMixin ¶

    Bases: GenericAPIView

    Add POST :batchDelete: {"ids": [...]}, all or nothing, 204.

    Ids are matched within filter_queryset(get_queryset()); an id outside it is a 404 problem naming the id. An error string from :meth:validate_batch_delete_instance is a 403 problem pointing at the id.

    validate_batch_delete_instance(instance) ¶

    Return an error message for one delete target, or None when allowed.

    ResourceExportMixin ¶

    Bases: ListModelMixin, GenericAPIView

    Answer list as CSV or XLSX when the client asks for it.

    Accept: text/csv, or ?format=csv, runs filter_queryset() then export_resource_class().export(). The result is not paginated. More rows than transfer.max_rows is a 422 problem naming the cap. Without a tabular Accept the JSON list is unchanged.

    Attributes:

    Name Type Description
    export_resource_class type[Any] | None

    An import_export.resources.Resource subclass.
    export_formats tuple[str, ...]

    Extensions offered; keys of :data:rn_forge.web.TABULAR_FORMATS.
    export_filename str | None

    The download name without extension; the router basename when unset.
    export_column_formats Mapping[str, str]

    Excel number format per header, for XLSX.

    get_export_resource() ¶

    Return the resource instance that builds the export.

    ResourceImportMixin ¶

    Bases: GenericAPIView

    Add POST :import and GET :importTemplate.

    :import takes a multipart/form-data file part (CSV, TSV, XLSX or ODS, by extension) and upserts through import_resource_class. The request user is passed to the resource as the user keyword, so before_import_row can set audit fields and authorize each row. The response is 200 with {created, updated, skipped, validateOnly}; with ?validateOnly=true nothing is persisted. Any row error is a 422 problem with errors[].pointer = "/rows/<row>/<column>" and nothing persisted.

    :importTemplate returns the import columns as an empty file, negotiated like an export; ?prefill=true adds the current filtered rows.

    Attributes:

    Name Type Description
    import_resource_class type[Any] | None

    An import_export.resources.Resource subclass.
    import_formats tuple[str, ...]

    Extensions accepted for upload and offered for the template.
    import_rollback_on_validation_errors bool

    False commits the valid rows and answers 200 with the failures listed under errors.

    get_import_resource() ¶

    Return the resource instance that performs the import.
