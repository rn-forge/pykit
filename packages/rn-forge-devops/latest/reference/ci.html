    Core¶

    rn_forge.devops.ci ¶

    The CI core: the member graph, change selection, check matrices and release gating.

    The core knows neither a CI platform nor a package manager. An adapter fills a Workspace from the repository's own manifests and formats the plan outputs for its platform.

    Package(name, dir, module, requires=(lambda: set[str]())(), postgres_env=None, smoke=None, adapters=None) dataclass ¶

    A workspace member.

    Attributes:

    Name Type Description
    name str

    Normalized project name.
    dir str

    Directory relative to the repository root, with / separators.
    module str

    Import name of the package.
    requires set[str]

    Names of the workspace members this package requires.
    postgres_env str | None

    Variable that receives a PostgreSQL DSN, or None when the package needs no database run.
    smoke Smoke | None

    The smoke-test declaration, or None when the package declares none.
    adapters list[str] | None

    Names of the package's adapters, or None when it declares none.

    checks() ¶

    Every check that must pass before this package may be released.

    The empty-extra smoke check is listed whether or not smoke is set.

    Smoke(modules=list[str](), extras=dict[str, list[str]](), setup='') dataclass ¶

    A package's smoke-test declaration.

    Attributes:

    Name Type Description
    modules list[str]

    Modules imported in every smoke run.
    extras dict[str, list[str]]

    Modules imported for each extra, keyed by extra name.
    setup str

    A script, relative to the package directory, run before the imports.

    Workspace(root, packages, pytest_args=list[str](), suites=dict[str, list[str]]()) dataclass ¶

    A repository root, its members and its workspace-wide CI settings.

    Attributes:

    Name Type Description
    root Path

    The repository root.
    packages dict[str, Package]

    The members, keyed by normalized name.
    pytest_args list[str]

    Arguments added to every package's pytest run.
    suites dict[str, list[str]]

    Workspace-wide pytest runs, keyed by suite name.

    changed_files(root, base) ¶

    Return the paths changed between base and HEAD.

    Raises:

    Type Description
    ValueError

    When base is not a plain revision name.

    normalize(name) ¶

    Return name in its canonical form: lowercase, runs of -_. as one -.

    plan(workspace, base) ¶

    Return every job's matrix and package list for a run against base.

    Command-line values are shell-quoted strings. The keys are release-order, packages, postgres, smoke, suites, pytest-args, cov-args, test-paths, sonar-sources, sonar-tests, sonar and docs.

    releasable(packages, ok_dir, names) ¶

    Return the packages of names that may be released, then those that may not.

    A package may be released when every check of it left a marker file in ok_dir and its requirements among names may be released too. Both lists are in release order.

    release_order(packages, names) ¶

    Return names with every package after its internal requirements.

    released(workspace) ¶

    Return (name, dir, module, version) for each <name>-v<version> tag at HEAD.

    requirement_name(requirement) ¶

    Return the normalized package name of a requirement string.

    select(workspace, base) ¶

    Return the packages with changed files, plus every package that depends on one.

    An empty, invalid or non-ancestor base, or a change outside every package and UNSCOPED, selects all. A base is invalid unless it matches REVISION.
